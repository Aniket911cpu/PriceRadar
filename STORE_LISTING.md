# Chrome Web Store listing

**Short description:** Track prices privately across stores and get transparent alerts.

**Single purpose:** Help users record product prices and receive user-configured price alerts.

The extension stores tracking data locally by default, does not inject affiliate links, and requests optional host access only when a user tracks a domain. Reviewer verification: load `dist`, open a product page containing JSON-LD Product data, click Track in the overlay, and open the popup to view the item.
